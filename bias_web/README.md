# 커뮤니티 정치 성향 분석 웹

주요 온라인 커뮤니티의 **최근 인기글**을 수집해 두 개의 축으로 정치 성향을 추정하는 웹 앱입니다.

- **좌우 축**: 진보(좌) ↔ 보수(우) (-100 ~ +100)
- **정파(계파) 축**: 진영 안에서 어느 계파에 우호적인지. **부모-자식 트리**로 구성된다.
  - 진보: 친문(문재인) · 친명/개딸(이재명) · 비명/반명 · 친조국(조국혁신당)
    - 친명/개딸 ▸ **뉴이재명**(하위 갈래)
  - 보수: 친윤(윤석열) · 친한(한동훈) · 친박(박근혜) · 이준석계(개혁신당) · 안철수계
- **하위 갈래(roll-up)**: 자식 정파의 매칭은 부모로 자동 집계된다. 우세 정파는
  `친명·개딸 › 뉴이재명` 처럼 가문 › 하위 갈래로 표시된다.
- **분기점 표시**: 같은 진영 안에서 대립 계파가 동시에 두드러지면 "⚡ 분기점"으로 표시
  (예: 보수 진영에서 친윤 vs 친한)

## 정파 트리 추가/수정

정파는 `bias_web/factions.json` 에 정의되며, **코드 수정 없이** 노드만 추가하면
새 갈래가 반영된다. 정치 지형이 계속 분화하므로 이 파일만 갱신하면 된다.

```json
{
  "id": "new_jaemyung",
  "name": "뉴이재명",
  "camp": "prog",
  "parent": "chinmyung",        // 부모 정파 id (없으면 null)
  "pro": ["뉴이재명", "실용이재명"],
  "anti": [],
  "opposes": []                 // 같은 진영 내 대립 정파 id (분기점 판단용)
}
```

- `parent` 를 지정하면 분석 시 자식→부모로 자동 집계(roll-up)된다.
- 긴 키워드를 먼저 매칭·소거하는 전역 스캔을 쓰므로, `뉴이재명` 이 부모의 `이재명` 에
  중복 집계되지 않는다.

## 실행

```bash
pip install -r requirements.txt
python -m bias_web.server
# http://localhost:5000
```

환경변수: `PORT`(기본 5000), `DEBUG`(설정 시 디버그 모드).

## 화면

- **커뮤니티 분석 탭**: 버튼을 누르면 각 커뮤니티 인기글을 수집·분석해 좌우 미터 +
  우세 계파 + 분기점 + 분석한 인기글 목록을 카드로 보여줍니다.
- **텍스트 분석 탭**: 게시글/댓글을 붙여넣으면 좌우·정파 성향을 추정합니다.

## 데이터 수집과 한계

`bias_web/sources.py`의 `COMMUNITIES`에 커뮤니티별 RSS 피드 URL을 지정하면 실시간으로
인기글을 가져옵니다. **접속이 실패하면 자동으로 번들 샘플(`sample_data.py`)로 폴백**하며,
이 경우 결과 카드에 `샘플` 배지가 표시됩니다.

> ⚠️ 상당수 커뮤니티는 RSS를 제공하지 않거나 봇 접근을 차단(403/Cloudflare)합니다.
> 또한 허용목록 기반의 네트워크 환경(예: 일부 클라우드/샌드박스)에서는 외부 사이트 접속이
> 막혀 항상 샘플로 폴백합니다. 실제 라이브 수집은 외부 네트워크가 열린 환경에서 동작하며,
> 사이트별 파서 추가가 필요할 수 있습니다.

## 구조

```
bias_web/
├── server.py        # Flask 앱 (HTML + JSON API)
├── lexicon.py       # 좌우 축 사전 + 정파 트리 로드/집계/점수 계산
├── factions.json    # 정파(계파) 트리 정의 — 새 갈래는 여기에 추가
├── sources.py       # 커뮤니티 인기글 수집 어댑터 (RSS, 샘플 폴백)
├── sample_data.py   # 오프라인/데모용 샘플 인기글
├── analyzer.py      # 수집 + 분석 결합
└── static/index.html
```

## 주의

결과는 키워드 빈도 기반의 **대략적 추정**이며, 같은 사이트라도 게시판·시기·이슈에 따라
편차가 큽니다. 특정 개인의 성향을 단정하지 않으며 재미·참고용입니다.
