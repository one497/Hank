# 슬라이드 생성 스크립트

`deck.js`는 `../제주드론치안_발제초안.pptx`를 생성하는 pptxgenjs 스크립트다.
내용을 수정할 때 pptx를 직접 편집해도 되지만, 구조를 크게 바꿀 때는 이 스크립트를 고쳐 다시 생성하는 편이 빠르다.

```bash
npm install pptxgenjs
node deck.js ../제주드론치안_발제초안.pptx
```

## 사양

- 12장 / 16:9 (10 × 5.625 inch)
- 글꼴: 맑은 고딕 (윈도우 PowerPoint 기본 탑재)
- 색: 네이비 `10243A` 주조 · 딥블루 `065A82` 보조 · 코랄 `E0523C` 강조
- 표지·마지막 장은 다크, 본문은 라이트 (샌드위치 구조)

## 수정이 필요한 부분

- 1번 슬라이드 `[회사명]`, `[OOO 대표]` — 실제 정보로 교체
- 회사 솔루션·실적 슬라이드를 추가한다면 6번(DFR)과 8번(제언 ①) 사이가 자연스럽다
- 지도 이미지(제주 지형, 시범 8개소 위치)를 넣으면 5번·8번 슬라이드의 설득력이 크게 올라간다. 현재는 텍스트 칩으로 대체돼 있다

## 검증 상태

- `validate.py` 스키마·관계·콘텐츠타입 검사 통과
- 좌표 경계 및 텍스트 넘침 자동 점검 통과
- **이미지 렌더링 기반 육안 검수는 하지 못했다** (작업 환경에 LibreOffice Impress 미설치). PowerPoint에서 한 번 열어 글자 넘침과 줄바꿈을 확인할 것
