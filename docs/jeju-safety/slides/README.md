# 슬라이드 생성 스크립트

`deck.js`는 `../진짜지도_발표자료.pptx`를 생성한다.

```bash
npm install pptxgenjs
node deck.js ../진짜지도_발표자료.pptx
```

## 사양

- 12장 / 16:9 (10 × 5.625 inch) / 맑은 고딕
- 어두운 화면(1·2·3·12번)과 밝은 화면(4~11번)을 나눴다. **감정 구간은 어둡게, 설명 구간은 밝게**
- 색: 네이비 `0E1F33` 주조 · 딥블루 `0A6B8A` 보조 · 앰버 `D9822B` 강조
- 숫자는 786 / 19,096 / 3분 셋뿐이다. 의도적으로 줄였다

## 반드시 손봐야 할 것

- **5번 슬라이드의 점선 박스에 대표님 현장 사진을 넣는다.** 실제로 찍은 사진이어야 한다. 스톡 이미지를 쓰면 이 발표는 죽는다
- 1번 슬라이드 `[회사명]`, `[OOO]` 교체
- **2번 슬라이드**: 단어를 쓰지 않기로 하면 텍스트를 "요즘 제주를 부르는 별명"으로 바꾼다 (발표 메모에 적어 뒀다)

## 손대면 안 되는 것

- **괴담 이미지 원본을 3번 슬라이드에 넣지 않는다.** 띄우는 순간 그 자리에서 또 한 번 퍼뜨리는 셈이다. 현재의 카드 대비로 충분하다
- 10번 슬라이드 하단 출처 각주는 지우지 않는다
- 사건 현장 사진, 피해자 관련 이미지, 실제 SNS 게시물 캡처는 한 장도 쓰지 않는다

## 검증 상태

스키마 검증과 좌표·텍스트 넘침 자동 점검은 통과했다. **다만 작업 환경에 LibreOffice Impress가 없어 렌더링 기반 육안 검수는 하지 못했다.** PowerPoint에서 한 번 열어 확인할 것.

## 발표 메모

각 슬라이드의 발표자 노트에 진행 지시를 적어 뒀다. 특히 2번(3초 침묵)과 5번(현장 이야기)을 확인할 것.
