## 발제 한 줄 요지

> 제주는 치안 자원이 부족한 곳이 아니다. 비어 있는 것은 **카메라가 닿지 않는 공간**과 **자동으로 작동하지 않는 초동 절차**, 두 곳뿐이다.

핵심 구조: **자료 확인(자원은 충분, 범죄율 1위는 분모 문제)** → **공백 두 곳(공간 / 절차)** → **해법(동원형 → 상시 출동형 DFR, 관제망의 이동형 확장 + 자동 기록)** → **제언 3개(거점 / 규제 / 거버넌스)** → **다목적 활용(치안·재난·수자원·환경)**

> ⚠️ **`05_근거자료_문제정의.md`를 먼저 읽을 것.** 문제 정의는 공개 통계에 기반해 세웠고, 쓰면 안 되는 논법 세 가지("범죄율 1위라 위험하다", "인력이 부족하다", "CCTV를 더 깔자")도 그 문서에 정리돼 있다.

- 특정 실종·범죄 사건의 세부 내용을 자극적으로 인용하지 않는다. 피해자·유족을 특정하지 않는다.
