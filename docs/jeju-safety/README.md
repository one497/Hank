## 이 발표가 무엇인가

정책제안이 아니다. **현장에서 일해온 사람이 경험에서 출발해 대안을 말하는 1인칭 발표**다.

> **"귤보디아라는 말이 싫었습니다. 그런데 반박할 말이 없었습니다. 그래서 지도를 만들기로 했습니다."**

제목: **「진짜 지도」** · 부제: "귤보디아"라는 말이 싫어서 — 땅을 재던 사람이 시작한 일

**구조**: 화가 났다 → 나는 땅을 재는 사람이다 → 현장에서 늘 겪는 일 → 이번 일도 똑같았다 → 점만 있는 지도 vs 진짜 지도 → **재고·짓고·남긴다** → 부정 말고 증명하면 된다

**재고·짓고·남긴다**는 회사 역량 세 가지(드론 측량 / 토목 시공 / 관제·데이터)와 1:1로 맞는다. 이것이 이번 기획의 축이다.
